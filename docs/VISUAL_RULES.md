# Правила production-визуала

## Масштаб и опорная точка

- Персонажи, NPC и питомцы ставятся на мир нижней опорной точкой силуэта; прозрачные поля исходного PNG компенсируются `origin` из manifest.
- Экранный размер задаётся visible target manifest, а не размером исходного canvas PNG. Player/NPC/Pet/tree/lamp масштабируются по высоте, здания и остальные world objects — по ширине.
- Runtime PNG обрезаются one-time скриптом по alpha threshold `16` с padding `12 px`; runtime-обработка изображений отсутствует.
- Масштаб можно корректировать в manifest после visual QA, не меняя physics body.

## Depth

- Динамические сущности используют Y-depth: объект ниже на карте рисуется поверх объекта выше.
- Здания и крупный декор получают depth по нижней точке визуала.
- Ground, дороги, вода, площадки и delivery markings остаются ниже персонажей.
- UI и world labels не участвуют в физике и имеют отдельные уровни depth.

## Коллизии

- Production PNG — только визуальный слой. Источник истины для физики — существующие Arcade colliders и navigation blockers.
- Прозрачный размер изображения не используется для автоматического collider generation.
- Декор без прежней геймплейной коллизии не получает новую коллизию только из-за появления PNG.

## Отражение, tint и переиспользование

- Отражение разрешено только для ассетов с `flipAllowed: true`.
- Tint допустим для функциональных вариаций общих зданий, станций, ворот и декора; питомцы и ключевые персонажи сохраняют исходные цвета.
- Один универсальный ассет предпочтительнее копий, если роль остаётся визуально читаемой.

## Fallback

- Отсутствующий или не загрузившийся PNG заменяется существующим prototype visual.
- Development сообщает об отсутствующем asset один раз; пользовательский режим продолжает работу без технического сообщения.
- Fallback сохраняет игровую позицию и прежнюю collision geometry.

## Земля, дороги и постоянные подписи

- Ground использует маленькие повторяемые процедурные textures, созданные один раз; world-sized PNG и per-frame noise запрещены.
- Дороги рисуются статическими Graphics: тёмная тёплая кромка и светлая внутренняя поверхность.
- Постоянные prototype territory/yard/building labels в production не показываются. Разрешены gate status до открытия, objective marker, contextual prompt и динамический счётчик общего загона.
- Perspective PNG нельзя поворачивать на 90°. Для несовместимой ориентации используется программный объект.
- Декор группируется и не получает collision без геймплейной необходимости.

## Mobile-first QA

- Силуэты игрока, питомца и преследователя должны различаться на узком экране.
- Production-визуал не должен перекрывать contextual prompt, joystick, dash и HUD.
- После resize/orientation change проверяются origin, depth, камера и читаемость объектов у границ экрана.
