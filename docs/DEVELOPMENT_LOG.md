# Журнал разработки

В этом файле фиксируются только важные долгосрочные решения проекта. Временные детали и мелкие изменения сюда не записываются.

## Решения

### 2026-07-30 — Исходный GDD и базовая концепция

- Утверждена концепция «Укради Питомца!» / Steal a Pet!: короткая законченная браузерная игра для Яндекс Игр с ориентиром около 20 минут на первое прохождение.
- Утверждён основной цикл: украсть питомца, доставить его на базу, получать доход, развиваться, открывать новые возможности и переходить к более ценным питомцам.
- Утверждены четыре уровня редкости питомцев и финальная легендарная цель — дракон.
- Утверждена одна непрерывная top-down карта с зонами STARTER SUBURB, PARK, CENTRAL HUB, RICH DISTRICT и VIP ESTATE.
- Утверждено яркое детское 2D-направление с псевдо-3D объёмом, высокой читаемостью и mobile-first UI.
- Утверждён технологический план: Phaser + TypeScript, mobile-first браузерная игра с поддержкой компьютеров.
- Числовой баланс, детальная архитектура и конкретные производственные параметры остаются **TBD** и требуют отдельных решений Game Director.

### 2026-07-31 — Архитектурная основа playable vertical slice

- Проект инициализирован на Phaser 4.2.1, TypeScript 7.0.2 и Vite 8.2.0.
- Выбрана простая модульная архитектура: одна композиционная `WorldScene`, отдельные entities, input, UI, world builder и системы core loop.
- Основной цикл управляется явными состояниями питомца, NPC и `CoreLoopSystem`, без ECS, DI framework или сложного pathfinding.
- Экономика отделена от UI и поддерживает суммирование независимых источников дохода.
- Временная карта и графика создаются программно; координаты и числовые значения Этапа 1 считаются technical prototype values, а не финальными решениями Game Director.
- Production build остаётся статическим и не зависит от серверной логики, чтобы не препятствовать будущей публикации в Яндекс Играх.

### 2026-07-31 — Первая прогрессионная арка и сохранение

- Утверждена первая последовательность кампании: Собака `COMMON` → доход `+1/сек` → открытие PARK за 25 монет → Кот `UNCOMMON` с доходом `+2/сек` → цель CENTRAL HUB.
- Утверждены четыре редкости: `COMMON`, `UNCOMMON`, `RARE`, `LEGENDARY`; Дракон остаётся финальной `LEGENDARY` целью.
- Прогрессия отделена от HUD и экономики в `ProgressionSystem`; зоны открываются физическими reusable gates непосредственно в мире.
- Питомцы и встречи описываются data definitions, а runtime поддерживает несколько `Pet + Owner + Encounter` при одной активной краже.
- Состояние первой арки сохраняется локально в versioned формате `saveVersion: 1`; загрузка восстанавливает деньги, открытые зоны, питомцев на базе, доход и objective.

### 2026-07-31 — Ограничение runtime и dirty-update политика

- Игровой loop ограничен максимумом 60 FPS, при этом все движения и игровые таймеры остаются delta/time-based.
- Для Phaser Text, visibility и cooldown Graphics принята dirty-update политика: одинаковое отображаемое состояние повторно не применяется, cooldown квантизируется на небольшое число визуальных шагов.
- Dev DOM и F2 performance overlay обновляются с частотой 4 раза/сек, чтобы диагностический режим не создавал существенную нагрузку.
- Суммарный income кэшируется и пересчитывается только при изменении набора источников.
- Статическая prototype-карта пока сохраняет текущие Graphics-слои; переход на chunked textures допускается только после подтверждённого GPU bottleneck при росте контента.

### 2026-07-31 — CENTRAL HUB, безопасный возврат NPC и первое улучшение

- Утверждена последовательность CENTRAL HUB: gate за 75 монет → Лиса `RARE` с доходом `+5/сек` → общий доход `+8/сек` → «Быстрый рывок» за 50 монет с cooldown 650 мс → preview RICH DISTRICT.
- Возврат владельцев стал data-driven: encounter может задавать несколько waypoint-маршрутов, а общий progress/timeout fail-safe гарантирует выход из `RETURNING` и повторную доступность кражи.
- Постоянные улучшения отделены от Player в `UpgradeSystem` и применяются через типизированные effect targets.
- Сохранение переведено на `saveVersion: 2`; состояние выводится из питомцев, открытых зон и купленных upgrades, а корректный v1 автоматически мигрирует без потери Dog/Cat/PARK/денег.
- RICH DISTRICT до отдельного этапа остаётся физически закрытым preview без misleading navigation marker.

### 2026-08-03 — RICH DISTRICT, несколько преследователей и Double Dash

- Утверждён RICH DISTRICT как четвёртая полноценная зона: physical gate стоит 200 монет и требует CENTRAL HUB, доставленную Лису и купленный Fast Dash.
- Утверждены два `RARE` питомца в свободном порядке: Павлин с доходом `+10/сек` и Панда с доходом `+14/сек`; итоговый доход пяти питомцев равен `+32/сек`.
- Encounter-модель расширена до массива независимых pursuers. Panda encounter использует владельца и охранника с cancel-safe задержкой тревоги; поимка одним участником завершает кражу для всех.
- Утверждено улучшение «Двойной рывок» за 250 монет: два runtime charges восстанавливаются последовательно по одному каждые 650 мс.
- Этап 4 сохраняет формат `saveVersion: 2`; новые zone, pets и upgrade представлены существующими массивами, а logical validation расширена без сброса корректного прогресса Этапа 3.
- VIP ESTATE остаётся следующей финальной зоной и после Этапа 4 показывается только неинтерактивным preview; Дракон остаётся финальной `LEGENDARY` целью.
