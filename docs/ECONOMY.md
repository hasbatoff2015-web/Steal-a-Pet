# Экономика

## Назначение

Экономика поддерживает короткую активную кампанию: питомцы дают пассивный доход, но игрок в периоды накопления исследует мир и ловит roaming pets. UI только отображает данные; `EconomySystem` хранит деньги, кэширует суммарный доход, проверяет и выполняет расходы.

## Текущий баланс

Действует `balanceRevision: 2`. Полная числовая таблица, контрольные суммы, цены, prerequisites и теоретические интервалы находятся в [BALANCE_MODEL.md](./BALANCE_MODEL.md).

- стартовые деньги: `0`;
- core income: Собака 1, Кот 2, Лиса 4, Павлин 7, Панда 9, VIP A 14, VIP B 18, Дракон 40;
- roaming income: Прыгун 1, Енот 1, Альпака 2, Хамелеон 2, Газель 3, Мини-грифон 3;
- итог после восьми core pets: `+95/сек`;
- итог после шести roaming pets: `+12/сек`;
- итоговая сумма 14 питомцев: `+107/сек`.

Цены зон: PARK 25, CENTRAL HUB 120, RICH DISTRICT 600, VIP ESTATE 2800.

Цены улучшений: Трекер питомцев 120, Fast Dash 200, Улучшенная приманка 450, Беговые кроссовки 800, Double Dash 1100, Тихие кроссовки 1400.

## Правила

- Каждый доставленный `PetId` регистрируется как отдельный income source.
- Повторное добавление того же source id заменяет значение и не дублирует доход.
- Суммарный income пересчитывается только при добавлении/удалении источника.
- При загрузке доход восстанавливается из актуальных `PetDefinition`, а не из сохранённой суммы; поэтому мигрированные saves автоматически используют revision 2.
- Покупка выполняется только после общей проверки prerequisites и `canAfford`; `spend` реально уменьшает баланс.
- Накопленный остаток сохраняется, но активное начисление не симулируется за время закрытой вкладки.
