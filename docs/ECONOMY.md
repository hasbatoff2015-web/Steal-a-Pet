# Экономика

## Назначение

Экономика связывает доставку питомцев, пассивный доход и физическое открытие новых частей мира. Она должна поддерживать короткую законченную кампанию примерно на 20 минут и не превращать игру в длительное idle-ожидание.

## Утверждённый баланс первой прогрессионной арки

Значения ниже утверждены Game Director для первой балансировочной версии:

| Параметр | Значение |
| --- | ---: |
| Стартовые деньги | 0 монет |
| Собака `COMMON` | +1 монета/сек |
| Открытие PARK | 25 монет |
| Кот `UNCOMMON` | +2 монеты/сек |
| Суммарный доход Собаки и Кота | +3 монеты/сек |
| Открытие CENTRAL HUB | 75 монет |
| Лиса `RARE` | +5 монет/сек |
| Суммарный доход трёх питомцев | +8 монет/сек |
| Улучшение «Быстрый рывок» | 50 монет |
| Dash cooldown после улучшения | 650 мс вместо 900 мс |
| Открытие RICH DISTRICT | 200 монет |
| Павлин `RARE` | +10 монет/сек |
| Панда `RARE` | +14 монет/сек |
| Суммарный доход пяти питомцев | +32 монеты/сек |
| Улучшение «Двойной рывок» | 250 монет |
| Открытие VIP ESTATE | 800 монет |
| VIP Pet A `RARE` | +24 монеты/сек |
| VIP Pet B `RARE` | +36 монет/сек |
| Суммарный доход семи питомцев | +92 монеты/сек |
| Дракон `LEGENDARY` | +100 монет/сек |
| Итоговый доход восьми питомцев | +192 монеты/сек |

После доставки Собаки накопление 25 монет без дополнительных расходов занимает около 25 секунд. Это соответствует требованию коротких циклов, но ощущение темпа подлежит игровому review без самостоятельного изменения цены или дохода.

После первых трёх питомцев доход равен `+8/сек`, поэтому 200 монет для RICH DISTRICT с нулевого остатка накапливаются примерно за 25 секунд. После Павлина и Панды итоговый доход равен `+32/сек`; 250 монет для Double Dash с нулевого остатка — примерно 7,8 секунды. Фактический остаток зависит от денег, накопленных во время перемещения и погонь.

После пяти питомцев накопление 800 монет для VIP ESTATE с нулевого остатка занимает около 25 секунд при `+32/сек`. VIP A увеличивает доход на `+24/сек`, VIP B — на `+36/сек`; свободный порядок даёт промежуточный общий доход `+56/сек` либо `+68/сек`. После обоих общий доход равен `+92/сек`. Доставка Дракона добавляет `+100/сек` и доводит финальный доход до `+192/сек`.

## Источники дохода

- Каждый доставленный питомец регистрируется как отдельный источник дохода.
- Общий доход равен сумме доходов всех доставленных питомцев.
- Доход продолжается после расходования денег.
- Питомец начинает приносить деньги только после успешной доставки на базу.
- Повторная регистрация одного и того же питомца не должна удваивать его доход.

## Расходы и открытие зон

- Деньги можно проверять на достаточность и списывать через экономическую систему.
- PARK покупается непосредственно у физических ворот на мосту, без магазина или отдельного меню.
- При открытии PARK со счёта действительно списываются 25 монет.
- CENTRAL HUB покупается у физического gate за 75 монет после доставки Кота.
- «Быстрый рывок» покупается у станции на базе за 50 монет после доставки Лисы.
- RICH DISTRICT покупается у физического gate за 200 монет после CENTRAL HUB, Лисы и «Быстрого рывка».
- «Двойной рывок» покупается на той же станции за 250 монет после доставки Павлина и Панды.
- VIP ESTATE открывается физическим gate за 800 монет после пяти питомцев, RICH DISTRICT и обоих dash upgrades.
- После Дракона новые обязательные покупки не добавляются.
- Открытая зона остаётся открытой в рамках сохранения.

## Редкость и ценность

Утверждены четыре редкости:

| Код | Русское название | Текущий пример |
| --- | --- | --- |
| `COMMON` | Обычный | Собака |
| `UNCOMMON` | Необычный | Кот |
| `RARE` | Редкий | Лиса, Павлин, Панда, VIP A, VIP B |
| `LEGENDARY` | Легендарный | Дракон |

Редкость влияет на ценность питомца и является частью прогрессии. Полная формула зависимости дохода от редкости: **TBD**.

## Темп прогрессии

- Первый доход появляется после доставки доступной Собаки.
- Рост дохода ускоряет последующие этапы кампании.
- Игрок должен регулярно получать понятное действие или награду; ориентир — 20–60 секунд.
- Во время накопления денег игрок видит PARK, его стоимость и рост счётчика.
- Полное первое прохождение должно ориентировочно укладываться примерно в 20 минут.

## Техническая реализация

`EconomySystem` отделён от HUD. Он хранит текущее количество денег, суммирует именованные источники дохода и предоставляет операции `canAfford`, `spend` и `addIncomeSource`. Баланс задаётся централизованно в data definitions питомцев и zone gates, а не дублируется в игровых классах.
