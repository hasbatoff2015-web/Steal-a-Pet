# Game Design Document — «Укради Питомца!»

## Концепция

Яркая mobile-first браузерная top-down игра для Яндекс Игр. Игрок физически уводит питомцев из мира на свою базу, переживает короткие комичные погони, получает доход и открывает новые части одной большой карты. Целевой первый проход — короткая законченная кампания, а не бесконечный idle-проект.

## Основной цикл

`найти/украсть или поймать → унести за собой → доставить на базу → получать деньги → купить доступ/улучшение → открыть следующий маршрут`.

Понятные действия и награды должны следовать примерно каждые 20–60 секунд. HUD показывает только ближайшую цель.

## Два источника питомцев

### HEIST

Игрок подходит к питомцу на NPC-базе, взаимодействует, получает физически следующего за ним питомца и запускает data-driven погоню владельцев. При поимке питомец возвращается, игрок может сразу повторить попытку. На базе погоня прекращается.

### ROAMING

Свободный питомец бродит в ограниченной безопасной территории. При приближении игрока он замечает угрозу, убегает по waypoint graph и расходует stamina. В состоянии TIRED он медленнее, но продолжает двигаться; в коротком окне доступно `E`/touch «ПОЙМАТЬ». Пропущенное окно частично восстанавливает stamina. После захвата используется тот же breadcrumb follow, доставка, base slot, income и save fact, что и для HEIST.

Одновременно можно переносить только одного питомца. Активный перенос блокирует остальные theft/capture/gate/upgrade interactions. Инвентаря нет.

## Питомцы и редкости

Редкости: COMMON / Обычный, UNCOMMON / Необычный, RARE / Редкий, LEGENDARY / Легендарный.

Восемь core pets: Собака, Кот, Лиса, Павлин, Панда, временные VIP A/Золотая Капибара и VIP B/Королевская Сова, финальный Дракон.

Шесть roaming pets: Прыгун, Енот, Альпака, Хамелеон, Газель, Мини-грифон. Финальные brainrot-названия и production-дизайны roaming/VIP pets — TBD; стабильные gameplay ids сохраняются.

## Прогрессия мира

Платные зоны открываются непосредственно через видимые gates. Дополнительные shortcuts появляются из фактов доставки и сокращают уже пройденные маршруты, но не обходят первоначальную покупку зоны. Физическое открытие мира и видимая следующая территория важнее роста абстрактных чисел.

## Улучшения

Три ветки представлены физическими станциями на базе:

- Mobility: Fast Dash → Runner Shoes → Double Dash;
- Tracking: Pet Tracker → Calming Lure;
- Stealth: Quiet Shoes.

Все эффекты типизированы в data definitions и применяются системами, а не HUD или отдельными encounter-id checks.

## База и коллекция

База вмещает 14 раздельных pets: core showcase, центральное место Дракона и отдельный roaming-загон `0/6…6/6`. Питомцы остаются видимыми, имеют лёгкий idle и являются источниками дохода. Строительство и ручная перестановка не реализуются.

## Победа

Победа по-прежнему наступает при доставке Дракона. Чистая новая кампания приходит к нему с `14/14`, поскольку VIP gate требует всех roaming pets. Мигрированное старое completed-сохранение остаётся победой при `8/14`; последующая доставка последнего roaming pet показывает «КОЛЛЕКЦИЯ ЗАВЕРШЕНА!» без второго victory overlay.

## Не входит в текущий этап

Финальная графика, audio, Yandex SDK, реклама, cloud save, магазин, строительство, combat, health, inventory, сложный stealth, navmesh и procedural generation не реализованы. Их параметры — TBD.
