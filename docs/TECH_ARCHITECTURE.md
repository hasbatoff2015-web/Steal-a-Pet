# Техническая архитектура

## Текущее состояние

Игровой проект ещё не инициализирован. В репозитории нет Phaser-проекта, игрового кода, сцен, механик, конфигурации сборки или игровых ассетов.

Сейчас репозиторий содержит только README, документацию проекта и правила совместной работы.

## Утверждено

### Целевая платформа

- Браузерная игра для Яндекс Игр.
- Подход mobile-first.
- Игра должна нормально работать на компьютерах.

### Технологический стек

- Phaser.
- TypeScript.

Версии Phaser, TypeScript и остальных инструментов: **TBD**.

### Формат игры

- 2D top-down.
- Одна большая непрерывная игровая карта.
- Ориентировочный размер мира: 3840 × 2560 px.
- Свободное перемещение персонажа.
- Ориентир продолжительности первого прохождения: около 20 минут.

### Управление

- Клавиатурное управление на компьютере.
- Виртуальное управление и/или тач на мобильных устройствах.
- Конкретная схема ввода и поведение виртуальных контролов: **TBD**.
