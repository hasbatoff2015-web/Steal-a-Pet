# Последний выполненный этап

Исправления review для Этапа 1 — Playable Core Vertical Slice.

## Что сделано

- В Phaser настроено `input.activePointers: 3` для одновременной работы нескольких пальцев.
- Joystick продолжает принадлежать первому pointer ID; нажатия dash и contextual interaction другими указателями не сбрасывают движение.
- В mobile-режиме убрана отдельная верхняя desktop-полоса dash cooldown.
- Mobile-кнопка «РЫВОК» теперь сама показывает состояние: активная при готовности, затемнённая во время cooldown и с кольцом прогресса восстановления.
- Compact HUD переразложен для узких экранов: цель и деньги находятся на разных вертикальных уровнях, а строка активного дохода использует подходящий размер шрифта.
- Следование питомца переведено с прямой цели позади игрока на ограниченную breadcrumb-историю реально пройденного маршрута.
- При большом отставании питомец корректируется к безопасной точке breadcrumb-маршрута, а не прямо к координатам позади игрока.
- Архитектура и существующие переходы core loop не менялись; новый контент и Этап 2 не начинались.

## Технические решения

- Phaser создаёт три активных указателя. Virtual controls разделяют joystick и action-кнопки по событиям отдельных pointers.
- Повторный pointer на joystick игнорируется, пока им владеет первый палец. Освобождение dash/interact pointer не влияет на joystick, потому что сброс движения выполняется только для сохранённого joystick pointer ID.
- Mobile dash feedback реализован существующими Phaser Game Objects без сторонней библиотеки и тяжёлых эффектов.
- `PlayerPathHistory` хранит максимум 160 точек с шагом 18 px только как TypeScript-данные. Игровые объекты для breadcrumbs не создаются.
- Питомец последовательно проходит доступные точки с дистанцией задержки 76 px. Это сохраняет его на реально пройденном маршруте вокруг крупных препятствий без navmesh.
- При отставании более 560 px используется correction к trailing breadcrumb. Все значения остаются техническими параметрами прототипа в `config/gameplay.ts`.

## Проверки

- `npm run typecheck` — успешно, ошибок TypeScript нет.
- `npm run build` — успешно, production-сборка создана. Сохраняется известное предупреждение Vite о размере Phaser bundle.
- Desktop runtime загружен в браузере: сцена, карта, камера и HUD отображаются корректно.
- В desktop runtime повторно проверены contextual prompt, кража, переходы `FOLLOWING_PLAYER` / `CHASING`, поимка и доступность повторной попытки.
- Desktop dash indicator сохранён и отображается отдельно в верхней части HUD.
- Для ширин 320, 360, 390 и 430 px проверена геометрия compact layout: objective заканчивается на `y = 66`, money panel начинается на `y = 76`; пересечения нет.
- Для mobile landscape 844 × 430 рассчитанная область objective находится между панелью денег и правым краем; верхний dash UI в mobile-режиме скрыт.
- Строка `МОНЕТЫ: 10 +1/сек` измерена системным Arial Bold: около 144 px при 14 px и 154 px при 15 px; она помещается в mobile money panel шириной 200 px с внутренними отступами.
- Проверены `git diff --check`, состав изменений и отсутствие `node_modules` / `dist` среди подготовленных файлов.
- Полноценный физический multi-touch и финальный mobile screenshot не удалось воспроизвести после того, как локальная вкладка браузерного контроллера перешла на защищённую страницу ошибки при таймауте dev-сервера. Конфигурация указателей и независимость pointer ID проверены по реализации; необходим короткий hands-on тест на реальном touch-устройстве.
- Следование по сложному маршруту вокруг всех препятствий проверено по алгоритму и typecheck, но окончательная визуальная оценка плавности требует ручного playtest.

## Остались проблемы

- Автоматизированная среда не заменила реальный тест одновременного удержания joystick и нажатия dash/interact двумя пальцами.
- Параметры spacing, follow distance и catch-up speed могут потребовать небольшой настройки после визуального playtest; это не изменение геймдизайна.
- Существующие ограничения Этапа 1 сохраняются: нет persistence, SDK Яндекс Игр, audio, lint и автоматических unit/integration tests.

## Требуется решение Game Director

- Проверить на телефоне сценарии: удержание joystick + dash вторым пальцем и удержание joystick + contextual interaction вторым пальцем.
- Оценить плавность breadcrumb-following на поворотах вокруг воды, зданий и крупных препятствий.
- Принять или вернуть Этап 1 после повторного hands-on review.
