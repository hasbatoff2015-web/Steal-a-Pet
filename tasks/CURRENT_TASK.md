# Текущая задача

## Статус

Активная техническая задача не назначена. Проект ожидает первый технический этап от Game Director.

## Цель

Ожидать постановку первого технического этапа от Game Director. Не начинать разработку самостоятельно.

## Ограничения

- Не инициализировать Phaser-проект без отдельной задачи.
- Не создавать игровой код, сцены, механики или ассеты без отдельной задачи.
- При постановке первого этапа использовать утверждённую документацию из `docs/`.
