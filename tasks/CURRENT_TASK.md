# Этап 1 — Playable Core Vertical Slice

## Статус

COMPLETED — AWAITING GAME DIRECTOR REVIEW

## Цель

Создать запускаемый browser/mobile-first прототип на Phaser + TypeScript, который демонстрирует полный основной цикл:

`НАЙТИ → УКРАСТЬ → УБЕЖАТЬ → ДОСТАВИТЬ НА БАЗУ → ПОЛУЧАТЬ ДЕНЬГИ`.

Вертикальный срез должен стать простой, качественной и расширяемой технической основой для следующих этапов.

## Объём

- Инициализировать проект Phaser + TypeScript + Vite + npm.
- Создать модульную структуру исходного кода.
- Создать одну большую top-down сцену размером 3840 × 2560 px.
- Реализовать прототипную планировку пяти зон, дороги, воду, мост, базы и препятствия.
- Реализовать Arcade Physics, коллизии, камеру и корректный resize.
- Реализовать Player, keyboard/touch movement и dash.
- Реализовать одну NPC-базу, владельца и обычного питомца.
- Реализовать contextual theft interaction, следование питомца, погоню, провал и повторную попытку.
- Реализовать доставку питомца, безопасную delivery zone и завершение погони.
- Реализовать тестовую экономику с пассивным доходом и mobile-first HUD.
- Показать будущую прогрессию через зоны и маркер PARK.
- Обновить README и фактическую техническую документацию.

## Критерии готовности

- [x] Проект запускается через `npm run dev`.
- [x] `npm run typecheck` и `npm run build` проходят.
- [x] Реализованы keyboard и mobile/touch movement, dash и коллизии.
- [x] Камера следует за игроком и остаётся в границах мира.
- [x] Полностью работает цикл кражи, погони, поимки/повторной попытки и доставки.
- [x] Доставленный питомец остаётся на базе и создаёт тестовый пассивный доход.
- [x] HUD показывает деньги и следующую цель.
- [x] Карта читаемо показывает пять будущих зон.
- [x] Игра сохраняет работоспособность после resize.
- [x] Код разделён на понятные модули, документация соответствует реализации.

## Ограничения

- Не создавать полную игру или контент всех зон.
- Не добавлять финальные или сторонние художественные ассеты.
- Не интегрировать SDK Яндекс Игр.
- Не добавлять audio, сложный stealth, navmesh, ECS или тяжёлые фреймворки.
- Не утверждать прототипные координаты и экономические значения как финальный геймдизайн.
- Не начинать Этап 2 самостоятельно.
