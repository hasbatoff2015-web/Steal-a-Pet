# Этап 2 — Progression, Park Unlock and Multiple Pets

## Статус

COMPLETED — AWAITING GAME DIRECTOR REVIEW

## Цель

Расширить vertical slice первой прогрессионной аркой:

`Собака → доход → 25 монет → открытие PARK → Кот → суммарный доход → цель CENTRAL HUB`.

Этап должен заложить расширяемую основу прогрессии по карте, нескольких питомцев и NPC encounters, физических zone gates и локального сохранения.

## Текущий review pass

Стабилизировать runtime до добавления нового контента, не меняя геймдизайн, карту, баланс, скорости, стоимость PARK, доход или механику кражи и погони.

- Ограничить игровой loop максимумом 60 FPS.
- Убрать повторные одинаковые обновления Phaser Text, visibility и Graphics.
- Квантизировать desktop/mobile dash cooldown.
- Ограничить dev DOM snapshot и F2 performance overlay частотой 4 раза/сек.
- Кэшировать суммарный income.
- Проверить основной update path и статический мир без ненужного rewrite.
- Добавить `npm run preview` и сравнить dev с production preview.
- После проверок вернуть статус `COMPLETED — AWAITING GAME DIRECTOR REVIEW`.

## Объём

- Добавить отдельную `ProgressionSystem` с состояниями первой арки кампании.
- Создать единые data definitions питомцев, редкостей и encounters.
- Расширить существующий core loop для активной кражи одного из нескольких питомцев.
- Реализовать Собаку COMMON `+1/сек` и Кота UNCOMMON `+2/сек`.
- Реализовать reusable physical zone gate и покупку PARK за 25 монет непосредственно в мире.
- Наполнить PARK отличимым prototype-окружением, NPC-владельцем и Котом.
- Оставлять доставленных питомцев видимыми в отдельных местах базы.
- Поддержать списание денег и суммирование нескольких источников дохода.
- Добавить `SaveSystem` с `saveVersion: 1`, восстановлением денег, прогрессии, gates, питомцев и income sources.
- Добавить dev-only reset save.
- Обновлять HUD и навигационные маркеры по текущему состоянию прогрессии.

- Обновить фактическую документацию и отчёт.

## Критерии готовности

- [x] Core loop Этапа 1 остаётся работоспособным.
- [x] Несколько питомцев и NPC encounters поддерживаются данными и архитектурой.
- [x] PARK закрыт до покупки и открывается за 25 монет с реальным списанием.
- [x] Собака приносит `+1/сек`, Кот — `+2/сек`, вместе — `+3/сек`.
- [x] Оба питомца можно украсть, потерять при поимке и доставить на базу.
- [x] Погоня Кота заметно сложнее, но использует существующую систему.
- [x] После доставки оба питомца видимы на базе и не перекрываются.
- [x] `ProgressionSystem` управляет текущей целью и открытыми зонами.
- [x] `SaveSystem` корректно восстанавливает деньги, PARK, питомцев, доход и objective.
- [x] Повреждённый или отсутствующий save запускает новую игру без ошибки.
- [x] Dev reset save работает только в debug/dev режиме.
- [x] Mobile contextual purchase/theft сохраняют независимость от joystick.
- [x] После завершения PARK показана цель CENTRAL HUB.
- [x] `npm run typecheck` и `npm run build` проходят.
- [x] Документация соответствует реализации.
