# Этап 4 — Rich District, Multiple Pursuers and Double Dash

## Статус

COMPLETED — AWAITING GAME DIRECTOR REVIEW

## Цель

Превратить RICH DISTRICT в четвёртую полноценную зону кампании и расширить существующий core loop:

`Собака → PARK → Кот → CENTRAL HUB → Лиса → Быстрый рывок → RICH DISTRICT → Павлин/Панда → Двойной рывок → preview VIP ESTATE`.

Этап должен поддержать свободный порядок двух питомцев RICH DISTRICT, встречу с несколькими преследователями и постоянное улучшение с двумя последовательными зарядами dash, не ломая Этапы 1–3 и сохранения v2.

## Объём

- Сделать RICH DISTRICT физически открываемой зоной с data-driven prerequisites по питомцам, улучшениям и открытым зонам.
- Создать читаемый prototype layout богатого района с главным бульваром, двумя estate, широкими маршрутами и закрытым preview VIP ESTATE.
- Добавить Павлина `RARE` с доходом `+10/сек` и Панду `RARE` с доходом `+14/сек`.
- Поддержать свободный порядок доставки Павлина и Панды при одной активной краже.
- Расширить encounter-модель до `pursuers[]`; Panda encounter содержит владельца и охранника с отменяемой задержкой alarm.
- Гарантировать единичную обработку поимки, возврат всех преследователей и повторную доступность encounter.
- Расширить базу до пяти раздельных pet slots и суммарного дохода `+32/сек`.
- Добавить улучшение `double-dash`, последовательное восстановление двух charges и desktop/mobile HUD charges.
- Сохранить формат `saveVersion: 2`, расширить логическую валидацию и восстановление мира после reload.
- Добавить targeted tests на чистую логику через Vitest и dev-only инструменты QA.
- Обновить документацию, выполнить runtime/regression/performance проверки и подготовить один проверенный commit.

## Утверждённый баланс

- RICH DISTRICT: 200 монет.
- Павлин `RARE`: `+10 монет/сек`.
- Панда `RARE`: `+14 монет/сек`.
- Общий доход пяти питомцев: `+32 монеты/сек`.
- «Двойной рывок»: 250 монет.
- После Fast Dash один заряд восстанавливается каждые 650 мс; Double Dash повышает максимум до двух charges.
- Скорость dash, длительность dash и обычная скорость игрока не меняются.

- [x] Gate prerequisites задаются data-driven через required pets, upgrades и zones.

- [x] Питомцев RICH DISTRICT можно доставить в любом порядке; итоговый доход равен `+32/сек`.
- [x] Panda encounter запускает владельца сразу и охранника после 700–900 мс без неотменяемых timers.

- [x] Старые корректные save v2 загружаются; новые зависимости валидируются; reload восстанавливает Rich progress, income и upgrades без дублирования.

- [x] `npm run typecheck`, `npm run test`, `npm run build`, production preview и `git diff --check` проходят.
