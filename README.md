# Укради Питомца!

«Укради Питомца!» / Steal a Pet! — короткая browser/mobile-first 2D top-down игра для Яндекс Игр. Игрок крадёт питомца с чужой базы, уходит от погони, доставляет питомца домой и получает от него доход.

Сейчас в репозитории находится первый playable core vertical slice с временной графикой из Phaser-примитивов.

## Технологии

- Phaser 4.2.1 с Arcade Physics
- TypeScript 7.0.2
- Vite 8.2.0
- npm

## Требования

- Node.js `^20.19.0` или `>=22.12.0`
- npm
- современный браузер с поддержкой WebGL или Canvas

## Установка и запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес игры в терминал.

## Проверки и сборка

```bash
npm run typecheck
npm run build
```

Статическая production-сборка создаётся в `dist/`.

## Управление на компьютере

- `WASD` или стрелки — движение
- `Space` — рывок
- `E` — украсть питомца, когда доступна contextual-подсказка
- `F2` — показать или скрыть техническую информацию

## Управление на мобильном устройстве

- виртуальный joystick слева — движение;
- кнопка «РЫВОК» справа — dash;
- contextual-кнопка «УКРАСТЬ» появляется рядом с питомцем.

Виртуальные элементы автоматически включаются для touch/coarse-pointer устройств и перестраиваются после resize или смены ориентации.

## Режим QA

Параметр `?dev=1` включает техническую панель для ускоренной проверки кражи, погони, поимки, доставки и dash. Панель выключена в обычном режиме игры и не является частью игрового интерфейса.

## Статус

Реализован только первый вертикальный срез. Финальные ассеты, полный контент карты, баланс, сохранение, аудио и SDK Яндекс Игр пока не добавлены.
