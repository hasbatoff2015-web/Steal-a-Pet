# Укради Питомца!

«Укради Питомца!» / Steal a Pet! — короткая browser/mobile-first 2D top-down игра для Яндекс Игр. Игрок крадёт питомца с чужой базы, уходит от погони, доставляет питомца домой и получает от него доход.

Сейчас в репозитории находится полная системная prototype-кампания: пять основных зон, восемь питомцев в heist encounters, шесть roaming-питомцев с лёгким waypoint AI, шесть улучшений в трёх ветках, финальная погоня за Драконом и коллекция `14/14`. Графика временная и создаётся Phaser-примитивами и generated prototype textures.

## Технологии

- Phaser 4.2.1 с Arcade Physics
- TypeScript 7.0.2
- Vite 8.2.0
- npm

## Требования

- Node.js `^20.19.0` или `>=22.12.0`
- npm
- современный браузер с поддержкой WebGL или Canvas

## Установка и запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес игры в терминал.

## Проверки и сборка

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

Статическая production-сборка создаётся в `dist/`. `npm run preview` запускает локальную проверку этой production-сборки.

## Управление на компьютере

- `WASD` или стрелки — движение
- `Space` — рывок
- `E` — contextual interaction: кража, открытие gate или покупка улучшения
- `F2` — показать или скрыть FPS, rolling FPS, frame time и состояния runtime

## Управление на мобильном устройстве

- виртуальный joystick слева — движение;
- кнопка «РЫВОК» справа — dash;
- contextual-кнопка появляется для кражи, поимки уставшего roaming pet, открытия gate и покупки улучшения.

Виртуальные элементы автоматически включаются для touch/coarse-pointer устройств и перестраиваются после resize или смены ориентации.

## Режим QA

Параметр `?dev=1` включает техническую панель для проверки heists, roaming AI, доставки, gates/upgrades, Dragon seals, saves и dash. Dev snapshot помечен `DEV RUN — TIME INVALID`.

Параметр `?playtest=1` включает компактную честную telemetry-панель без cheats и кнопку копирования обезличенного отчёта после победы. Для валидного измерения нужно начинать с чистого сохранения.

## Статус
